MySQL的使用

基础

1.相关概念

（1）数据库DataBase(DB)：存储数据的仓库，数据是有组织的的进行存储

（2）数据库管理系统DataBase Management System(DBMS)：操作和管理数据库的大型软件

（3）SQLStructured Query Language(SQL):操作关系型数据库的编程语言，定义了一套操作关系型数据库系统

2.主流的关系型数据库：

（1）Oracle

（2）MySQL

（3）Microsoft SQL Server

（4）PostgreSQL

（5）IBM Db2

（1）在r中输入services.mrs

（4）在cmd中使用mysql [-h 127.0.0.1] [-p 3306] -u root -p;（使用此操作需要配置环境变量）

MySQL概述

数据库类型

1.关系型数据库（RDBMS）：建立在关系模型基础上，由多张相互连接的二维表（像是excel表）组成的数据库

​ 特点：（1）表存储数据，格式统一，便于维护

​ （2）SQL语言操作，标准统一，使用方便

2.数据模型：

客户端—>DBMS—>数据库—>表

SQL

SQL通用语法

1.SQL语句以单行或多行书写，以分号结尾

2.SQL语句使用空格/缩进来增强语句的可读性

3.MySQL语句不区分大小写，关键字建议使用大写

4.注释：

（1）单行注释：– 注释内容（注意是有空格的）或# 注释内容（空格）（MySQL特有）

（2）多行注释：/注释内容/（有星号，跟编程语言一样）

SQL分类

1.分类

（1）DDL（Data Definition Language）：数据定义语言，用来定义数据库对象（数据库，表，字段）

（2）DML（Data Manipulation Language）：数据操作语言，用来对数据库表中的数据进行增删改

（3）DQL（Data Query Language）：数据查询语言，用来查询数据库表中的记录

（4）DCL（Data Control Language）：数据控制语言，用来创建数据库用户，控制数据库的访问权限

DDL（定义语言）

数据库操作

（1）查询：查询所有数据库 SHOW DATABASES;(结尾有s和；)

​ 查询当前数据库 SELECT DATABASE();

（2）创建：CREATE DATABASE IF NOT EXISTS 数据库名 [DEFAULT CHARSET 字符集] [COLLATE 排序规则]；（如果数据库存在，则会报错）(数据库名称会自动给你改成小写名称)

（3）删除：DROP DATABASE [IF EXITS] 数据库名

（4）使用：USE 数据库名；

（5）查看当前处于什么数据库当中：SELECT DATABASE()

（6）DROP DATABASE 数据库名；

（7）按键盘的上下键会调出最近执行的命令

表操作
查询表（通过use指令）

（1）查询当前数据库所有表：SHOW TABLES;

（2）查询表结构：DESC 表名；

（3）查询指定表的建表语句：SHOW CREATE TABLE 表名；

创建新表

CREAT TABLE 表名（

​ 字段1 字段1类型[COMMENT 字段1注释]，

​ ······

​ 字段n 字段n类型[COMMENT 字段n注释]

）[COMMENT 标注释];

(注意最后一个字段后面没有逗号)

修改表及表中字段

1.添加字段：ALTER TABLE 表名 ADD 字段名 类型（长度）[COMMENT 注释] [约束]；

2.修改字段名和字段类型：ALTER TABLE 表名 CHANGE 旧字段名 新字段名 类型（长度） [comment 注释] [约束]；

3.修改数据类型：ALTER TABLE 表名 MODIFY 字段名 新数据类型（长度）;

4.删除字段：ALTER TABLE 表名 DROP 字段名；

5.修改表名：ALTER TABLE 表名 RENAME TO 新表名；

6.删除表：DROP TABLE [IF EXITS] 表名；

7.删除指定表，并重新创建该表（清空）：TRUNCATE TABLE 表名；（只有表结构，没有数据）

DML（操作语言）

添加数据（INSERT）

1.给指定字段添加数据：INSERT TO 表名 （字段名1，字段名2，···） VALUES（值1，值2，···）；

2.给全部字段添加数据：INSERT INTO 表名 VALUES（值1，值2，···）；

3.批量添加数据：

（1）INSERT INTO （字段1，字段2，···） VALUES （值1，值2，···），（值1，值2，···）（值1，值2，···）；

（2）INSERT INTO 表名 VALUES（值1，值2，···），（值1，值2，···）

注意：（1）字段顺序和值的顺序是一一对应的

​ （2）字符串与日期型数据应该包含在引号当中

修改数据（UPDATE）

UPDATE 表名 SET 字段名1=值1，字段名2=值2，···[WHERE 条件]；

（符合修改这个条件的，如果没有，则修改整张表的所有数据）(这个是直接在表中修改的)

删除数据（DELETE）

DELECT FROM 表名 [WHERE 条件]；

（删除语句不能删除某一个字段的值）

DQL（查询语言）

1.常见语法：

（1）SELECT+字段列表

（2）FROM+表名列表

（3）WHERE+条件

（4）GROUP BY+分段字段列表

（5）HAVING+分组后条件列表

（6）ORDER BY+排序字段列表

（7）LIMIT+分页参数

基本查询

1.查询多个字段

（1）SELECT 字段1，字段2，字段3···FROM 表名；（会显现出所想要的数据）

（2）SELECT * FROM 表名；（不推荐使用*，因为不直观，其表示所有信息）

2.设置别名

SELECT 字段1 [AS 别名1]，字段2[AS 别名2]··· FROM 类名；（as也是可以省的）

3.去除重复记录

SELECT DISTINCT 子段列表 FROM 表名；

条件查询（SELECT）

1.语法：SELECT 字段列表 FROM 表名 [WHERE 条件列表]；

2.条件：比较运算符和条件运算符

（1）IN(…):在其中选择一个

（2）LIKE 占位符：模糊匹配（_匹配单个字符，%匹配任意个字符）（如果是字符，需要加单引号哦）

eg.查询姓名位两个字的；查询身份证号最后一位是X的

（3）<>:不等于

（4）IS NULL：是NULL

（5）BETWEEN AND可以表示选择一个范围（包含边界）

聚合函数（count（统计数量）,max,min,avg,sum）

1.简介：将一列数据作为一个整体，进行纵向计算

2.语法：SELECT 聚合函数（字段列表） FROM 表名；

3.NULL值不参与聚合函数的运算

4.这些条件都是可以叠加的

分组查询（GROUP BY）

1.语法：SELECT 字段列表 聚合函数 FROM 表名 [WHERE 条件] GROUP BY 分组字段名 [HAVING 分组后过滤条件]；

2.where与having的区别：

（1）执行时机不同：where是分组之前进行过滤，不满足where条件，不参与分组；而having是分组之后对结果进行过滤

（2）判断条件不同：where不能对聚合函数进行判断，而having函数可以

（3）where是筛选，having是统计

eg.查询年龄小于45的员工，并根据工作地址分组，获取员工数量大于等于3的工作地址

（1）select * from emp where age<45 ;

（2）select * from emp where age<45 group by workaddress;

（3）select workaddress count(一星)from emp where age<45 group by workaddress having count(一星)>=3;（注意这里查的是所有）

3.注意：

（1）执行顺序：where>聚合函数>having

（2）分组之后，查询的字段一般位聚合函数和分组字段，查询其他字段无任何意义

排序查询（ORDER BY）

1.语法：SELECT 字段列表 FROM 表名 ORDER BY 字段1 排序方式1，字段2 排序方式2；

2.排序方式：

（1）ASC：升序（默认值,可以不写）

（2）DESC：降序

3.注意：如果是多字段排序，当第一个字段值相同时，才会根据第二个字段进行排序

分页查询（LIMIT）

1.语法：SELECT 字段列表 FROM 表名 LINIT 起始索引，查询记录数；

2.注意：

（1）起始索引从0开始，起始索引=（查询页数-1）*每页显示记录数

（2）分页查询是数据库的方言，不同的数据库有不同的实现，MySQL中是LIMIT。

（3）如果查询的是第一页数据，起始索引可以省略，直接简写为limit 10。

（4）放在所有条件的最后

eg.(1)统计员工表中，年龄小于60岁的，男性员工和女性员工的人数

select gender,count(*) from emp where age<60 group by gender;(注意逗号和空格的位置)

（2）select name,age from emp where age<=35 order by age asc,entrydate desc;

（3）查询性别年龄为男，且年龄在20~40岁（含）以内的前5个员工信息，对查询的结果按年龄升序排序，年龄相同按入职时间升序排序

select * from emp where gender=’男’ and (age between 20 and 40) order by age,entrydate limit 0,5;（注意limit的位置）

执行顺序

1.编写顺序：

（1）SELECT:字段列表(表示可以跟多个数据)

（2）FROM:表名列表

（3）WHERE：条件列表

（4）GROUP BY:分组字段列表

（5）HAVING：分组后条件列表

（6）ORDER BY：排序字段列表

（7）LLIMIT:分页参数

2.执行顺序

FROM>WHERE>GROUP BY>HAVING>SELECT>ORDER BY>LIMIT

DCL（控制语言）

1.查询用户：USE mysql；SELECT * FROM user;

2.创建用户：CREAT USER ‘用户名‘@’主机名‘ IDENTIFIED BY ‘密码’；

3.修改用户密码：ALTER USER ‘用户名‘@’主机名‘ IDENTIFIED WITH mysql_native_password BY ‘新密码’；

4.删除用户：DROP USER ‘用户名‘@’主机名’；

5.注意：

（1）主机名可以使用%通配

（2）这类SQL开发人员操作的比较少，主要是DBA（Database Administrator 书记库管理员）使用

函数

1.定义：指一段可以直接被另一段程序调用的程序或代码

字符串函数

1.常用字符串函数

（1）CONCAT(S1,S2,···Sn)：字符串拼接

（2）LOWER(str)：将字符串转变为小写

（3）UPPER(str)：转化为大写

（4）LPAD(str,n,pad)：左填充，用字符串pad对str的左边进行填充，达到n个字符的长度

（5）RPAD(str,n,pad)：右填充

（6）TRIM(str)：去掉字符串头部和尾部的空格

（7）SUBSTRING(str,start,len)：返回从字符串str 从start位置起的len个长度的字符串（从1开始，如果不写len，是截取后面所有）

这些都是前面是select,加这些关键字，就能实现后面这些功能

eg.把员工号更新为5位

update emp set workno=(workno,5,’0’);

数值函数

1.常用函数：

（1）CEIL(x):向上取整

（2）FLOOR(x):向下取整

（3）MOD(x,y):返回x/y的模（余数）

（4）RAND():返回0~1的随机数（好多小数位）

（5）ROUND(x,y)：求参数x的四舍五入的值，保留y位小数

eg.随机生成一个六位数的随机验证码

select round(rand()*1000000,0);(但前面可能因为0，所以数位可能不会凑够6位)

select lpad(round(rand()*1000000,0),6,’0’);(这样可以补充0)

日期函数

1.常见函数（记着数字需要加引号）：

（1）CURDATE():返回当前日期；

（2）CURTIME():返回当前时间；

（3）NOW():返回当前日期和时间；

（4）YEAR(date):获取指定date的年份（eg.填入now()）

（5）MONTH(date):获取指定date的月份

（6）DAY(date):获取指定date的日期

（7）DATE_ADD(date,INTERAL expr type):返回一个日期/时间值加上一个时间间隔expr后的时间值(expr表示一个时间值，type表示一个时间单位)

eg.查询所有员工的入职天数，并根据入职天数倒序排序

select name,datediff(curdate(),entrydate) as ‘entrydays’ from emp order by entrydays desc;

约束

概述

1.概念：约束是作用与表中字段上的规则，用于限制存储在表中的数据（在建表和修改表的时候添加）

2.目的：保证数据库中数据的正确，有效性和完整性

3.分类：

（1）非空约束(NOT NULL)：限制改字段的数据不能为null

（2）唯一约束(UNIQUE)：保证该字段的所有数据都是唯一，不重复的

（3）主键约束(PRIMARY KEY)：主键是一行数据的唯一标识，要求非空且唯一（主键形如黄色小钥匙）

（4）默认约束(DEFAULT)：保存数据时，如果未指定该字段的值，则采用默认值

（5）检查约束(CHECK)：保证字段值满足某一个条件

（6）外键约束(FOREIGN KEY)：用来让两张表的数据之间建立连接，保证数据的一致性和完整性

（7）自动增长（AUTO_INCREMENT）：添加失败但也会申请主键，即在后面主键id会跳过该id

外键约束

概念

1.外键：另一张表的主键

2.主键的表成为父表（外键关联的表），引用主键的表称为子表(这里会出现蓝色的小钥匙)

语法

1.添加外键

CREAT TABLE 表名(

​ 字段名 数据类型，

​ ···

​ [COMSTAINT] [外键名称] FOREIGN KEY 外键字段名 REFRENCES 主键（主列表名）;

)

ALTER TABLE 表名 ADD CONSTRAINT 外键名称 FOREIGN KEY( 外键字段名) REFRENCES 主表（主列表名）;

2.删除外键

ALTER TABLE 表名 DROP FOREIGN KEY 外键名称；

3.删改/更新行为

（1）NO ACTION:当在父表删除/更新对应记录时，首先检查该记录是否有对应外键，如果有则不允许删除/更新。

（2）RESTRCT:（与NO ACTION一样）

（3）CASCADE:当在父表删除/更新对应记录时，首先检查该记录是否有对应外键，如果有，择业删除/更新外键在中的记录

（4）SET NULL:当在父表删除/更新对应记录时，首先检查该记录是否有对应外键，如果有，则设置子表中该外键值为null（这就要求该外键值允许取null）

（5）SET DEFAULT:父表有变更时，子表将外键设置成一个默认的值（Innodb不支持）

ALTER TABLE 表名 ADD CONSTRAINT 外键名称 FOREIGN KEY(外键字段) REFERENCES 主表名(主表名字段) ON UPDATE CASCADE ON DELETE CASCADE;

多表查询

多表关系

项目开发中，在进行数据库表结构设计时，会根据业务需求及业务模块之间的关系，分析并设计表结构，由于业务之间相互关联，所以各个表结构之间也存在着各种联系，基本上分为三种：

一对多（多对一）

1.案例：部门与员工的关系

2.关系：一个部门对应多个员工，一个员工对应多个部门

3.实现：在多的一方建立外键，指向一的一方主键

多对多

1.案例：学生与课程的关系

2.关系：一个学生可以选修多门课程，一门课程也可以供多个学生选择

3.实现：建立第三方中间表，中间表至少含有两个外键，分别关联两方主键

一对一

1.案例：用户与用户详情的关系

2.关系：一对一关系，多用于单表拆分，将一张表的基础字段放在一张表中，其他详情字段放在另一张表中，以提升操作效率

3.实现：在任意一方加入外键，关联另外一方的主键，并且设计外键为唯一（UNIQUE）
